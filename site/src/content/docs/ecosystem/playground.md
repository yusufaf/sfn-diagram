An interactive browser-based editor for exploring ASL definitions and previewing diagrams in real time. **[Open the live playground →](https://sfn.yusufaf.dev/playground/)** or run it locally from the [`playground/`](https://github.com/yusufaf/sfn-diagram/tree/main/playground/) directory.

```bash
cd playground
pnpm install
pnpm dev
```

Paste any ASL JSON, switch themes, and see the SVG diagram update instantly — no install required beyond the dev server. Switch **Mode** to _Execution overlay_ to paste an execution history alongside the definition and watch the run's path light up.
